# هنذاكروا

إعادة بناء تدريجية لمنصة «هنذاكروا». يحتوي هذا الفرع على أساس React + TypeScript + Vite، وتوجيه الصفحات، وواجهة أولية مستقلة لمساعد لؤي ولوحة مستخدم أساسية. الأكواد المسترجعة في `recovered-code/` غير مكتملة ومساراتها الأصلية غير معروفة، لذلك لا تُعامل كمشروع جاهز ولا تُشغّل ترحيلات SQL قبل مراجعتها.

## المتطلبات والتشغيل

- Node.js `22.12` أو أحدث.
- pnpm `11.25.0` (محدد في `package.json`).

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm build
```

## المسارات الحالية

- `/` — الصفحة العامة.
- `/dashboard` — لوحة مستخدم تأسيسية وروابط سريعة، بلا إحصاءات أو بيانات تجريبية.
- `/study` — مساحة المذاكرة التأسيسية.
- `/competitions` — صفحة المنافسات التأسيسية.
- `/vocabulary` — صفحة المفردات والتعلّم.
- `/assistant` — يحوّل إلى واجهة لؤي المستقلة في `/chat`.
- `/chat` — معاينة محادثة بملء الشاشة؛ الرسائل محلية ولا تُرسل إلى خدمة AI.

لا توجد حاليًا مصادقة أو صلاحيات أو صفحة إدارة مشرف. يلزم تحديد الأدوار وتأمين المسارات قبل إضافة عمليات إدارية.

## بنية المصدر

- `src/App.tsx`: جدول مسارات React Router.
- `src/layouts/AppLayout.tsx`: التخطيط المشترك لصفحات المنصة.
- `src/components/`: رأس الموقع وتذييله وقالب الأقسام.
- `src/features/dashboard/`: مكوّنات لوحة المستخدم.
- `src/features/assistant/`: مكوّنات المحادثة وأنواع رسائلها ومصادرها.
- `src/pages/`: صفحات المنصة ولوحة المستخدم ومحادثة لؤي.
- `src/main.tsx` و`src/index.css`: نقطة تشغيل React والتنسيقات.
- `public/manus-routes.json`: بيان المسارات الحالية.
- `recovered-code/source/`: وحدات TypeScript/TSX مسترجعة لم تُدمج بعد.
- `recovered-code/db-migrations/`: ترحيلات SQL محفوظة للمراجعة فقط.
- `recovered-code/REBUILD_AUDIT.md`: جرد أولي للنواقص وخطة إعادة البناء.

لا تضع مفاتيح أو بيانات دخول في Git؛ ستُحدد متطلبات الخادم والأسرار عند تنفيذ الربط الخلفي.
