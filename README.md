# هنذاكروا

إعادة بناء تدريجية لمنصة «هنذاكروا». يحتوي هذا الفرع على أساس React + TypeScript + Vite، وهيكلًا أوليًا للصفحات والتوجيه، بالإضافة إلى أكواد مسترجعة محفوظة في `recovered-code/`. المواد المسترجعة غير مكتملة ومساراتها الأصلية غير معروفة؛ لا تُعامل كمشروع جاهز ولا تُشغّل ترحيلات SQL قبل مراجعتها وربطها بالمخطط الصحيح.

## المتطلبات والتشغيل

- Node.js `22.12` أو أحدث.
- pnpm `11.25.0` (محدد في `package.json`).

```bash
pnpm install
pnpm dev
```

أوامر المشروع:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

## المسارات الحالية

- `/` — الرئيسية.
- `/study` — مساحة المذاكرة التأسيسية.
- `/competitions` — صفحة المنافسات التأسيسية.
- `/vocabulary` — صفحة المفردات والتعلّم.
- `/assistant` — صفحة مساعد لؤي التأسيسية.
- أي مسار آخر يعرض صفحة 404.

الصفحات الأربع الداخلية تعلن صراحة أنها قيد التجهيز؛ لا توجد بعد خلفية أو بيانات حسابات أو خدمات خارجية مرتبطة بها.

## بنية المصدر

- `src/App.tsx`: جدول مسارات React Router.
- `src/layouts/AppLayout.tsx`: الهيكل المشترك للصفحات.
- `src/components/`: رأس الموقع وتذييله وقالب الأقسام.
- `src/pages/`: الرئيسية وصفحات الأقسام وصفحة 404.
- `src/main.tsx` و`src/index.css`: نقطة تشغيل React والتنسيقات.
- `public/manus-routes.json`: بيان المسارات الحالية.
- `recovered-code/source/`: وحدات TypeScript/TSX مسترجعة لم تُدمج بعد.
- `recovered-code/db-migrations/`: ترحيلات SQL محفوظة للمراجعة فقط.
- `recovered-code/REBUILD_AUDIT.md`: جرد أولي للنواقص وخطة إعادة البناء.

تُحفظ الأسرار في إعدادات بيئة محلية أو خدمة أسرار مناسبة، ولا تُرفع إلى Git.
