# هنذاكروا

إعادة بناء تدريجية لمنصة «هنذاكروا». يحتوي هذا الفرع الآن على أساس واجهة React + TypeScript + Vite، بالإضافة إلى مجموعة أكواد مسترجعة محفوظة في `recovered-code/`. المواد المسترجعة غير مكتملة ومساراتها الأصلية غير معروفة؛ لذلك لا تُعامل كمشروع جاهز ولا تُشغّل ترحيلات SQL قبل مراجعتها وربطها بالمخطط الصحيح.

## المتطلبات والتشغيل

- Node.js `22.12` أو أحدث.
- pnpm `11.25.0` (محدد في `package.json`).

```bash
pnpm install
pnpm dev
```

أوامر المشروع:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

## هيكل البداية

- `src/App.tsx`: واجهة عربية تأسيسية توضّح أن المنصة قيد البناء.
- `src/main.tsx` و`src/index.css`: نقطة تشغيل React والتنسيقات الأساسية.
- `vite.config.ts`: خادم التطوير والبناء.
- `public/manus-routes.json`: المسارات الحالية التي يعرفها المشروع.
- `recovered-code/source/`: وحدات TypeScript/TSX مسترجعة لم تُدمج بعد.
- `recovered-code/db-migrations/`: ترحيلات SQL محفوظة للمراجعة فقط.
- `recovered-code/REBUILD_AUDIT.md`: جرد أولي للنواقص وخطة إعادة البناء.

تُحفظ الأسرار في إعدادات البيئة المحلية أو خدمة أسرار مناسبة، ولا تُرفع إلى Git.
