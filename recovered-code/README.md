# Recovered code artifacts (not a complete application)

This folder contains source-code artifacts recovered from the referenced Manus task. The task exposed standalone files, not the original repository tree, so original directory paths and dependency relationships are unavailable. Files are grouped only by type: `source/` contains TypeScript/TSX modules and tests; `db-migrations/` contains SQL migration artifacts.

**This is not a deployable or buildable project by itself.** It does not include a verified application entry point, package manifest/lockfile, build configuration, environment setup, or all related modules. SQL migrations are preserved as files and have not been applied. Test files have not been run. Review and integrate these artifacts into the proper project structure before deployment.

Only the newest 200 listed task artifacts were considered. Temporary `.py`/`.mjs` task utilities, documentation, images, and configuration files were excluded. Candidate files containing common hard-coded credential patterns were excluded. See `MANIFEST.txt` for the retained filenames.
